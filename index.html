System Forecast

How EasyReplenish's 3-month forecast for each SKU is built, from recent sell-through through to seasonality.

Metrics used to build this forecast
  1. Last 90 days of sell-through, read as three rolling 30-day windows
  2. Trend — latest 30-day run-rate vs. the two 30-day windows before it
  3. Seasonality & festival calendar — expected uplift or dip for this forecast window
  4. Product lifecycle stage — new launch, best seller, slow mover, or non-mover
  5. For new launches: comparable-SKU launch curve, normalized to this zone
3-month total = latest 30-day run-rate × 3, adjusted for seasonality (new launches use a comparable-SKU curve instead). Sample data for this walkthrough — not Eveready's actual figures.
